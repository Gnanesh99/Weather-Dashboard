🌦 Weather Dashboard

A modern Weather Dashboard web application that provides real-time weather information, hourly forecasts, and animated weather icons for any city. The application integrates with the OpenWeatherMap API to display accurate weather data and offers a responsive, visually appealing interface with features like dark mode, geolocation detection, and temperature charts.

🚀 Features

🌍 Search Weather by City – Get current weather details for any city worldwide

📍 Use My Location – Automatically detect your location using browser geolocation
